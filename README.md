# Skin-Disorder-Prediction
Developed a Skin Disorder Prediction System using Python and machine learning to classify six types of skin diseases. Performed data cleaning, EDA and feature analysis, and compared four algorithms. Achieved 97.30% accuracy using SVM to support early skin disorder identification.

## Project Overview
This project aims to predict six different types of skin disorders using machine learning techniques based on clinical and histopathological attributes of patients.

## Objectives
- Analyze skin disorder patient data.
- Perform data cleaning and exploratory data analysis (EDA).
- Build and compare multiple machine learning models.
- Predict skin disorder categories using patient-related features.

## Dataset Information
- Total Records: 366
- Input Features: 34
- Target Variable: Class
- Disease Categories: 6

### Skin Disorders
1. Psoriasis
2. Seborrheic Dermatitis
3. Lichen Planus
4. Pityriasis Rosea
5. Chronic Dermatitis
6. Pityriasis Rubra Pilaris

## Conclusion
The project successfully developed a machine learning-based skin disorder classification system. Among the four algorithms, SVM achieved the best performance with 97.30% accuracy and a 96.97% F1-score.
